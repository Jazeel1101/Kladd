# Screen capture on macOS

`ScreenCaptureDarwin` (`packages/platform-darwin/src/ScreenCaptureDarwin.ts`) runs `kladd-capture`, a Swift helper in `packages/platform-darwin/native`, once per call. Its usage is at the top of `native/Sources/KladdCapture/main.swift`. `FocusTrackerDarwin` runs the same helper for focus and Accessibility permission, which work the same way as below (`docs/internals/overlay-placement.md`). `SessionCaptureDarwin` runs its long-running `session` command, which also records the clips and, while it runs, takes the screenshots (`docs/internals/session-capture.md`).

- **Permission belongs to Kladd.** macOS attributes a child process's screen recording to the app that started it, so the grant is for Kladd (Electron.app in dev, or the terminal you launched it from).
- **Asking uses PermissionFlow** (`noxaur/PermissionFlow`): it opens System Settings → Screen Recording with a floating panel to drag Kladd.app into the list. `request` returns when the user grants it, quits System Settings, or after 5 minutes. Permission is then read again in a new process, because macOS may apply a grant only to processes started after it.
- **Video stops cleanly.** `record` and `session` finish their files on SIGINT, SIGTERM or stdin closing (Kladd exited); `record` records at least 1 second, since ScreenCaptureKit writes no file for a shorter one. `startCapture` in `src/helper.ts` runs both: `stop` (or closing the scope) sends SIGINT and waits for the exit; only `stop` reports a failure. Closing the PermissionFlow panel also ends `request`.
- **A screenshot gives up after 10 s** (`screenshotTimeout` in `src/helper.ts`) and kills its helper: ScreenCaptureKit can leave the call hanging for ever.
- **Building.** `vp run @kladd/platform-darwin#build:native` runs `native/build.sh` (`swift build`). It is a task in `packages/platform-darwin/vite.config.ts` with caching off, because vp can't see the files swift build reads and would replay a stale build. `pnpm dev` runs it first; `package` copies the binary and `PermissionFlow_PermissionFlow.bundle` (which it loads from beside itself) to `Resources/capture`. The helper needs macOS 15 (`SCRecordingOutput`).
- **Without Xcode** (`xcode-select -p` is Command Line Tools), `build.sh` sets `KLADD_NO_PERMISSIONFLOW=1`: PermissionFlow's SwiftUI macros only build with Xcode. That helper asks with the system prompt and opens the System Settings pane, with no drag panel, so grant Screen Recording and Accessibility to Electron.app (dev) by hand. `package` still needs Xcode for the PermissionFlow bundle.
- **Captures leave out Kladd's own windows** by excluding the Electron main process's pid.
