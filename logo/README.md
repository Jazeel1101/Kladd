# Kladd logo

A bound notebook with screenshot corner marks on the cover: screenshots become a log.

Brand colour: violet `#5B3DF5`. The logo is always one colour: violet, black or white.

| File                                            | Use                                                                                         |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `kladd-logo.svg`                                | Main logo: symbol and wordmark                                                              |
| `kladd-symbol.svg`                              | Symbol alone                                                                                |
| `kladd-wordmark.svg`                            | Wordmark alone                                                                              |
| `variants/kladd-logo-black.svg`, `-white.svg`   | One-colour logo for light and dark backgrounds                                              |
| `variants/kladd-symbol-black.svg`, `-white.svg` | One-colour symbol                                                                           |
| `variants/kladd-symbol-small.svg`               | Simplified symbol for sizes under about 32 px (no ribbon, wider spine gap)                  |
| `variants/kladd-symbol-app-icon.svg`            | White symbol on a violet rounded tile                                                       |
| `web/`                                          | Favicon and web app icons, `site.webmanifest`, and the `<head>` tags in `head-snippet.html` |

The paths in `web/site.webmanifest` and `web/head-snippet.html` assume the icons are served from the site root.

The wordmark is drawn as shapes, so no font is needed.
