# Glossary

Product talk (Linear) is Norwegian; code is English. Use the code name everywhere in code, and add a row before naming a new concept.

| Norwegian (Linear)               | Code name                                            | Meaning                                                                                                                                       | In code                                            |
| -------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| logg                             | `LogEntry`                                           | What the student writes about their work; Kladd's end product                                                                                 | not yet                                            |
| økt                              | `Session`                                            | A work period the student writes one section of their log about; started and ended from the pill, then logged; written to a session folder    | `packages/domain/src/Session.ts`                   |
| opptaksmodus (manuell / auto)    | `CaptureMode` (`"manual"` / `"auto"`)                | What a session captures, chosen before it starts: manual only what the student takes; auto also keyframes of the screen (not offered yet)     | `packages/domain/src/Session.ts`                   |
| loggemodus                       | `SessionState` `"ended"`                             | The pill's state after a session ends: the logging overlay opens, and the pill's checkmark marks the session logged                           | `apps/ui/src/pill/RecordingPill.tsx`               |
| øktstatus                        | `SessionState` (`"active"` / `"ended"` / `"logged"`) | Where a session is: capturing, waiting for its log (logging mode), or logged                                                                  | `sessionState` in `packages/domain/src/Session.ts` |
| overlegg                         | `Overlay`                                            | A small always-on-top window over other apps; one UI route each                                                                               | `packages/domain/src/Window.ts`                    |
| chat composer                    | `Composer`                                           | The overlay input where the user talks to the LLM                                                                                             | not yet                                            |
| oppsummering                     | `Summary`                                            | LLM-written summary of a session                                                                                                              | not yet                                            |
| notat                            | `Note`                                               | A saved piece of text or image from a session                                                                                                 | not yet                                            |
| BYOK                             | `ProviderKey`                                        | The user's own LLM API key; stays on the device                                                                                               | not yet                                            |
| sensitivt innhold                | `SensitiveContent`                                   | Content to keep out of recordings (auto mode, post-MVP)                                                                                       | not yet                                            |
| skjermopptak                     | `ScreenCapture`                                      | The port for screen permission, screenshots and screen video, implemented per OS                                                              | `packages/core/src/ports/ScreenCapture.ts`         |
| skjermopptakstillatelse          | `ScreenCapturePermission`                            | Whether the OS lets Kladd capture the screen (`"granted"` / `"denied"`)                                                                       | `packages/domain/src/ScreenCapture.ts`             |
| skjermbilde                      | `screenshot`                                         | A PNG of the main display, without Kladd's own windows                                                                                        | `ScreenCapture.screenshot`                         |
| vedlagt skjermbilde              | `Screenshot`                                         | A screenshot of the whole screen taken with ⌃⇧C or the pill during a session, saved in its folder with the focus at that moment               | `packages/domain/src/Screenshot.ts`                |
| skjermbildebrett                 | `ScreenshotTray`                                     | The current session's screenshots, newest first, and the one in flight                                                                        | `packages/domain/src/Screenshot.ts`                |
| skjermbildeflukt                 | `ScreenshotFlight`                                   | The animation flying a new screenshot from the screen into the pill; also its window                                                          | `apps/ui/src/screenshot/ScreenshotFlight.tsx`      |
| inntak                           | `intake`                                             | A tray sliding out of the pill to take in a new screenshot in its slot, then back                                                             | `apps/ui/src/pill/intake.ts`                       |
| skjermvideo                      | `recordVideo`                                        | A video file of the main display; not the same as a work session (økt) or a clip (klipp)                                                      | `ScreenCapture.recordVideo`                        |
| opptaksknapp / pille             | `RecordingPill`                                      | Overlay on the left screen edge showing recording state; Kladd's only presence                                                                | `apps/ui/src/pill/RecordingPill.tsx`               |
| festesone                        | `SnapZones`                                          | The screen edges where the pill docks when let go; shown while it is dragged                                                                  | `apps/ui/src/pill/SnapZones.tsx`                   |
| loggeoverlegg                    | `LoggingOverlay`                                     | Overlay next to where the user writes; opens when a session ends; holds the composer                                                          | `packages/core/src/logging/LoggingOverlay.ts`      |
| maksimert visning                | `ExpandedView`                                       | Overlay listing the past sessions with their screenshots; opened from the pill when no session is active                                      | `apps/ui/src/expanded/ExpandedView.tsx`            |
| tidligere økt                    | `PastSession`                                        | An ended session as the expanded view lists it                                                                                                | `packages/domain/src/PastSession.ts`               |
| app-adapter                      | `AppAdapter`                                         | Per-app rules for where the logging overlay sits and what it says the user writes in                                                          | `packages/domain/src/AppAdapter.ts`                |
| skrivested                       | `WritingTarget`                                      | The app and document the user writes in, as an adapter reports it                                                                             | `packages/domain/src/WritingTarget.ts`             |
| tilgjengelighetstilgang          | `AccessibilityPermission`                            | Whether the OS lets Kladd read other apps' windows and text fields                                                                            | `packages/domain/src/Focus.ts`                     |
| fokus                            | `FocusSnapshot`                                      | Front app, window frame and title, focused element and caret rects at one moment                                                              | `packages/domain/src/Focus.ts`                     |
| markert rad                      | `SelectedItem`                                       | A selected row in one of the focused window's lists, such as the current page                                                                 | `packages/domain/src/Focus.ts`                     |
| anker                            | `Anchor`                                             | The rect an overlay is placed next to                                                                                                         | `AppAdapter.anchor`, a `Rect`                      |
| plassering (ved siden av / inni) | `OverlayPlacement` (`"beside"` / `"inside"`)         | Whether an overlay sits beside its anchor or inside its top-right corner                                                                      | `packages/domain/src/Placement.ts`                 |
| opptaksmappe                     | `sessionFiles`                                       | The folder one work session is written to, in `sessions/`, with its screenshots and clips; the contract between capture and the summary agent | `packages/domain/src/SessionFolder.ts`             |
| tidslinje                        | `TimelineEvent`                                      | What happened when during an auto-mode session, one event per line of `timeline.jsonl`                                                        | `packages/domain/src/SessionFolder.ts`             |
| nøkkelbilde                      | `frame`                                              | A full-resolution screenshot an auto-mode session saves when focus or the screen changes, with its OCR text                                   | `TimelineEvent`, type `frame`                      |
| øktopptak                        | `SessionCapture`                                     | The port that runs an active session's capture: its clips and screenshots, and in auto mode its timeline and keyframes                        | `packages/core/src/ports/SessionCapture.ts`        |
| transkripsjon                    | `Transcriber`                                        | The port that turns a clip's speech into text with Whisper, on the Mac                                                                        | `packages/core/src/ports/Transcriber.ts`           |
| klipp                            | `Clips`                                              | A whole-screen video with sound and red strokes, taken with ⌥⇧C or the pill inside a work session; a session can hold many                    | `packages/core/src/session/Clips.ts`               |
| strek                            | `Mark`                                               | A red stroke the student draws on the screen during a clip by holding ⇧ and moving the pointer                                                | `packages/domain/src/SessionFolder.ts`             |
